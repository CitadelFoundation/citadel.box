# citadel.box
Public site for the Citadel Box private beta, published with GitHub Pages: the landing page and the beta-access portal at /portal/. The GM bootstrap command prints a marker; it does not install Box, start sign-in, or activate anything.

The portal checks beta access through the Citadel Foundation identity service, and anyone can check a wallet's current Sonic holdings as an informational guide. Installer download and device activation are not part of this preview.

Once published, visit https://citadel.box for the landing page and https://citadel.box/portal/ for beta access.
