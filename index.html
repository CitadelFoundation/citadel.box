What is Citadel Box?

Box is the software you install and run on your own machine. Home is its dashboard.

Can I try it today?

Box is in an invite-only private beta. GitHub invitations are personal; Citadel does not manage the access list. Google access follows the approved domain. This command runs a GM bootstrap. It does not install Box, does not start sign-in, and does not access a private payload. The Box download stays protected.

Member portal
What comes with Box?

Home is bundled with Box. Keep and Publishing Studio are early prototypes: Keep is for project notes, captured context and search; Publishing Studio is for preparing publication drafts. They are not finished products.

What does local-first mean here?

Box starts on your own machine. Citadel is being built around open protocols and services that can work together, with the aim of giving you more choice about where your software runs.
