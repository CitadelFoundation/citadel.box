About this beta

Taking part

Invitations are personal and offered at our discretion. Use the beta on your own devices; there is no arbitrary device cap. An invitation does not give you permission to resell or redistribute the beta.

What this portal records

Citadel's product direction is edge-first, with the aim of keeping personal data minimal. The current portal records are described below.

The portal uses your numeric GitHub account ID to check your invitation. Sign-in records include that ID and sign-in times.

This browser tab remembers a pending GitHub sign-in so you can return to it.

The admission journal records your numeric ID, the admission decision and its time, and the roster version used. Signing out does not delete that journal.

Private beta is for already-invited testers.

A little guidance.

What happens in this preview?

This local preview shows the sign-in, download and activation journey. No account is connected, no installer is downloaded, and no files or device keys are sent anywhere.

Why does the provider account matter?

In the proposed install journey, the provider account used to check private beta eligibility stays the account used for Box activation.

Which file is safe to share for activation?

The public activation request created by Box. A device private key must remain on the device and should never be uploaded.

Optional wallet enrollment and issuer information

Enrollment

This step records whether you choose to take part. Read the statement below before you use Record consent or Withdraw consent.

You choose the Citadel private beta program and the Sonic 146 opted-in issuer profile. No issuer is connected in this local portal, so authority stays pending until a live chain, contract, and code identity is proven. A wallet signature proves account control only. It does not send a transaction, approve a token, move funds, or attest holdings. Holdings qualification needs seven continuous days on Sonic 146 at 10,000,000 BZ or 20,000 effective veEQUAL, reconstructed from two finalized providers. A balance or a signature is not enough. The installer request is a separate check: checksums alone do not authenticate it. You can withdraw this consent. Private-beta leases end Thursday 00:00 UTC. This portal does not issue a lease.

Show this wallet address is yours

Sign in to show that you control the wallet address you enrolled. A signature does that. It is not a transaction, a token approval, or a holdings proof. An ordinary account signs with that address. A deployed contract wallet needs a separate check, and sign-in stays closed when that check cannot be completed. If a wallet type is not accepted, the status says so.



Holdings eligibility
Two finalized Sonic histories have to agree before holdings can qualify. A current balance or a wallet signature is not enough. This page cannot read the chain. A line that says the supplied history meets the policy is using that supplied history, and this page has not read the chain.

The issuer choice
This choice is separate from enrollment, and it is yours: leave it unset, opt in, or decline. It does not change your enrollment choice. Opting in asks for a live chain, a contract, and a code identity. Until a live issuer is connected, the status stays pending. Record consent and sign in before you request the installer.
